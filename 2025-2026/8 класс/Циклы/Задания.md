#Задания

0. Факториалом числа N называется произведение всех натуральных чисел не превосходящих N.
Напишите программу вычисляющую факториал по введённому N.

1. Напишите программу для нечётного числа вычисляющую произведение всех нечётных числел и аналогично для чётного.
Замечание: Чётные числа записувыются как 2к, нечётные как 2к+1

2. Пользователь вводит площадь прямоугольника с целочисленными сторонами, выведите все возможные неповторяющиеся пары сторон.

3. Пользователь вводит длинну гипотенузы прямоугольного треугольника, найдите все пары неповторяющихся целочисленных катетов.
Замечание: для получения корня из числа X пользуйтесь степенью: X**0.5

4. Пользователь вводит N, после чего вводит N целых чисел. Посчитайте их среднее(арифметическое) значение.
Среднее геометрическое значение.

5. \*Лифт двиагется по правилам:
- Спускаясь забираются все пассажиры с этажей на которых были нажаты кнопки.
- Спустившись на 1ый этаж, если были нажаты кнопки выше, лифт едет на этаж самой ранней из нажатых кнопок, после чего снова спускается на 1ый.
- Находясь на 1ом этажа лифт ожидает нажатия кнопки

Пользователь вводит N - число нажатых кнопок. Затем номера этажей на которых они были нажаты.
Каждая следующая кнопка нажимается после 1го спуска/подъёма лифта между этажами с нажатыми кнопками или 1ым.
Определите в каком порядке спустятся на 1ый этаж пассажиры, нажавшие кнопки, указывайте кто вышел одновременно.
