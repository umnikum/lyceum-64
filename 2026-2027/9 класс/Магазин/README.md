# Урок: Сводные таблицы и фильтры в LibreOffice Calc  
**Тема:** Склад продуктового магазина (доставки и продажи)

**Цель урока:**  
Научиться применять фильтры к таблицам и создавать сводные таблицы для анализа данных склада.

**Исходный файл:**  
`Склад_магазина.ods`  
В файле уже подготовлены три листа с данными:
- `Товары`
- `Поставки`
- `Продажи`

Дальнейшая работа ведётся только с этим файлом.

---

## Задание 1. Применение Автофильтра

### Что нужно сделать
1. Откройте файл `Склад_магазина.ods`.
2. На листах «Поставки» и «Продажи» включите **Автофильтр**.
3. Выполните фильтрацию:
   - На листе «Поставки» покажите только поставки от поставщика **МолЗавод**.
   - На листе «Продажи» покажите только продажи кассира **Иванова**.
4. После проверки результатов сбросьте фильтры.

### Памятка: как выполнить операции

**Включение Автофильтра**  
1. Щёлкните любую ячейку внутри таблицы с данными.  
2. Выберите в меню **Данные → Автофильтр**.  
3. В ячейках заголовков столбцов появятся кнопки со стрелками ▼.

**Фильтрация по значению**  
1. Нажмите кнопку со стрелкой ▼ в нужном столбце (например, «Поставщик» или «Кассир»).  
2. Снимите галочку **Все**.  
3. Установите галочку только напротив нужного значения.  
4. Нажмите **ОК**.

**Сброс фильтра**  
- Выберите **Данные → Фильтр → Сбросить фильтр**  
**или**  
- Откройте список фильтра и выберите пункт **Все**.

## Задание 2. Создание сводной таблицы по продажам

### Что нужно сделать
1. Перейдите на лист «Продажи».
2. Создайте сводную таблицу со следующими настройками:
   - **Поля строк:** Код_товара  
   - **Поля данных:**  
     - Сумма по полю «Количество»  
     - Сумма по полю «Цена_продажи»
3. Разместите сводную таблицу на **новом листе**.
4. Переименуйте новый лист в `Сводная_Продажи`.

### Памятка: как создать сводную таблицу

1. Щёлкните любую ячейку внутри таблицы на листе «Продажи».  
2. Выберите в меню **Вставка → Сводная таблица**  
   (альтернатива: **Данные → Сводная таблица → Вставить или изменить**).  
3. В диалоговом окне «Выбор источника» оставьте вариант **Текущий выбор** и нажмите **ОК**.  
4. В окне **Макет сводной таблицы**:
   - Перетащите поле **Код_товара** в область **Поля строк**.  
   - Перетащите поле **Количество** в область **Поля данных**.  
   - Перетащите поле **Цена_продажи** в область **Поля данных**.  
5. В нижней части окна в разделе «Результат» выберите **Новый лист**.  
6. Нажмите **ОК**.

**Переименование листа**  
Правой кнопкой мыши по ярлыку листа → **Переименовать** → введите `Сводная_Продажи` → Enter.

**Изменение функции агрегации** (если требуется)  
Дважды щёлкните по полю в области «Поля данных» → выберите нужную функцию (Сумма, Среднее, Количество и т.д.) → ОК.

**Редактирование уже созданной сводной таблицы**  
Щёлкните внутри сводной таблицы → **Вставка → Сводная таблица**  
или правой кнопкой мыши → **Свойства**.

## Задание 3. Использование фильтров в сводной таблице и анализ поставок

### Что нужно сделать
1. В сводной таблице на листе `Сводная_Продажи` добавьте поле **Кассир** в область **Фильтры**.
2. С помощью фильтра сводной таблицы оставьте только данные по кассиру **Иванова**.
3. Создайте вторую сводную таблицу на основе листа «Поставки»:
   - **Поля строк:** Поставщик  
   - **Поля данных:** Сумма по полю «Количество»
4. Разместите её на новом листе и переименуйте лист в `Сводная_Поставки`.
5. С помощью фильтра сводной таблицы оставьте только поставщика **Фруктовый рай**.

### Памятка: как работать с фильтрами сводной таблицы

**Добавление поля в область «Фильтры»**  
1. Щёлкните любую ячейку внутри сводной таблицы.  
2. Откройте макет сводной таблицы (**Вставка → Сводная таблица** или правой кнопкой → **Свойства**).  
3. Перетащите нужное поле (например, **Кассир** или **Поставщик**) в область **Фильтры**.  
4. Нажмите **ОК**.

**Применение фильтра в сводной таблице**  
1. Над сводной таблицей появится кнопка с названием поля фильтра.  
2. Нажмите стрелку ▼ рядом с этой кнопкой.  
3. Снимите галочки с ненужных значений, оставьте только нужные.  
4. Нажмите **ОК**.

**Создание второй сводной таблицы**  
Повторите шаги из Задания 2, используя данные листа «Поставки».

**Обновление сводной таблицы**  
Правой кнопкой мыши внутри сводной таблицы → **Обновить**.

---

## Дополнительные рекомендации

- Регулярно сохраняйте файл (**Файл → Сохранить**).
- Сводные таблицы **не обновляются автоматически** при изменении исходных данных — используйте команду **Обновить**.
- Для удобства просмотра можно закрепить строки заголовков:  
  **Вид → Закрепить → Закрепить строки и столбцы**.

**Критерии успешного выполнения урока:**
- На листах «Поставки» и «Продажи» корректно работает Автофильтр.
- Создана сводная таблица по продажам с фильтром по кассиру.
- Создана сводная таблица по поставкам с фильтром по поставщику.
