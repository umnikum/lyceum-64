# Кубок лицея 64 по боулингу
## Практическая работа в LibreOffice Calc

### Цель работы
Проанализировать результаты четырёх матчей школьного турнира по боулингу и определить чемпионов в разных номинациях.

### Исходные данные
Вам выданы 4 файла:
- `match1.csv`
- `match2.csv`
- `match3.csv`
- `match4.csv`

Каждый файл содержит броски игроков **по раундам** (фреймам).  
Игроки бросают по очереди. В одном раунде у игрока может быть 1 или 2 броска (3 броска — только в 10-м раунде при страйке или спэре).

Столбцы:
- **Матч** — номер матча
- **Раунд** — номер фрейма (1–10)
- **Игрок** — фамилия и имя
- **Бросок_в_раунде** — порядковый номер броска в текущем раунде
- **Кегли** — сколько кеглей сбито этим броском (0–10)
- **Счёт_после_раунда** — текущий счёт игрока после завершения раунда (заполняется только на последнем броске раунда)

## Задания

### Задание 1. Импорт данных
1. Создайте новый документ LibreOffice Calc.
2. Импортируйте каждый CSV-файл **на отдельный лист**.
3. Назовите листы: `Матч1`, `Матч2`, `Матч3`, `Матч4`.
4. Убедитесь, что первая строка распознана как заголовки.
5. Закрепите первую строку на каждом листе.

> **Важно:** объединять все данные на один лист **не нужно**.

---

### Задание 2. Результаты каждого матча
На каждом листе матча создайте справа (начиная со столбца H) небольшую итоговую таблицу:

| Игрок              | Финальный счёт | Количество бросков | Среднее кеглей за бросок |
|--------------------|----------------|--------------------|---------------------------|
| ...                | ...            | ...                | ...                       |

- **Финальный счёт** — последнее непустое значение в столбце «Счёт_после_раунда» для данного игрока.
- **Количество бросков** — сколько строк принадлежит этому игроку.
- **Среднее кеглей за бросок** = сумма всех кеглей игрока / количество бросков.

Отсортируйте таблицу по финальному счёту (по убыванию).

---

### Задание 3. Общая статистика игроков
Создайте новый лист **«Статистика»**.

Составьте таблицу по всем уникальным игрокам турнира:

| Игрок | Матчей сыграно | Общий счёт | Всего бросков | Среднее кеглей за бросок | Средний счёт за матч | Средний счёт за бросок |
|-------|----------------|------------|---------------|---------------------------|----------------------|------------------------|
| ...   | ...            | ...        | ...           | ...                       | ...                  | ...                    |

Используйте функции `СЧЁТЕСЛИ`, `СУММЕСЛИ` и обычные арифметические операции.

---

### Задание 4. Диаграммы
Создайте лист **«Диаграммы»** и постройте минимум три диаграммы:

1. **Столбчатая диаграмма** — Общий счёт каждого игрока за весь турнир.
2. **Столбчатая или линейчатая** — Среднее количество кеглей за бросок у каждого игрока.
3. **Круговая диаграмма** — Доля общего счёта топ-5 игроков.

Все диаграммы должны иметь:
- понятный заголовок
- подписи данных (где уместно)
- легенду

---

### Задание 5. Чемпионы турнира (финальное)
Создайте лист **«Чемпионы»**.

Определите и красиво оформите победителей в следующих номинациях:

| Номинация                        | Чемпион              | Результат      |
|----------------------------------|----------------------|----------------|
| Лучший общий счёт                |                      |                |
| Лучшее среднее кеглей за бросок  |                      |                |
| Лучший средний счёт за матч      |                      |                |
| Самый активный (больше всего бросков) |                 |                |
| Победитель матча 1               |                      |                |
| Победитель матча 2               |                      |                |
| Победитель матча 3               |                      |                |
| Победитель матча 4               |                      |                |

Внизу листа напишите краткий вывод (4–6 предложений): кто стал главным героем турнира и какие интересные наблюдения вы сделали.

Сохраните файл как `Кубок_боулинга_Фамилия.ods`.

## Памятка-туториал (все используемые операции)

### 1. Импорт CSV-файла
1. `Данные` → `Текст в столбцы` **или** просто перетащите файл в Calc.
2. Лучший способ: `Файл` → `Открыть` → выберите CSV.
3. В окне импорта:
   - Кодировка: **UTF-8**
   - Разделитель: **точка с запятой (;)**
   - Поставьте галочку «Первая строка как подписи столбцов»
4. После импорта сразу переименуйте лист.

### 2. Закрепление строки
Выделите **вторую** строку → `Вид` → `Зафиксировать строки и столбцы`.

### 3. Основные формулы
- Сумма: `=СУММ(диапазон)`
- Среднее: `=СРЗНАЧ(диапазон)`
- Количество: `=СЧЁТ(диапазон)` или `=СЧЁТЗ(диапазон)`

### 4. Функции с условием (очень нужны)
`=СУММЕСЛИ(диапазон_критериев; "Иванов Алексей"; диапазон_суммирования)`
`=СЧЁТЕСЛИ(диапазон; "Иванов Алексей")`
`=СРЗНАЧЕСЛИ(диапазон_критериев; "Иванов Алексей"; диапазон_среднего)`

### 5. Как найти финальный счёт игрока
Самый простой способ для школьников:
- Отфильтруйте данные по игроку (Автофильтр).
- Посмотрите последнее заполненное значение в столбце «Счёт_после_раунда».
- Или используйте формулу (продвинутый вариант):
`=ВПР(1;ЕСЛИ((A:A=имя)*(F:F<>"");F:F);1)`
(вводится как формула массива).

Рекомендуется для большинства — просто визуально или через фильтр.

### 6. Создание диаграммы
1. Выделите данные (включая заголовки).
2. `Вставка` → `Диаграмма`.
3. Выберите тип (Столбчатая / Круговая / Линейчатая).
4. На вкладках мастера:
 - Дайте название диаграмме
 - Включите подписи данных
 - Настройте легенду
5. Диаграмму можно перенести на отдельный лист.

### 7. Сортировка таблицы
Выделите таблицу → `Данные` → `Сортировка` → выберите столбец и порядок (по убыванию).

### 8. Автозаполнение формул
Напишите формулу в первой ячейке → наведите на маленький квадратик в правом нижнем углу → потяните вниз.

### 9. Форматирование чисел
Выделите ячейки → правая кнопка → `Формат ячеек` → Число → число десятичных знаков (для среднего обычно 1 или 2).
